# 视频流连接初始化配置

> 技术栈:Vue 3 + TypeScript + 飞渡 AirCity 数字孪云 SDK
> 涉及文件:`src/components/VideoStreamPlayer.vue`、`src/stores/onReady.ts`、`src/stores/handleEvent.ts`、`src/aircity.d.ts`

## 一、初始化链路

```
组件 onMounted
  └─ initPlayer()
       ├─ 检查 window.DigitalTwinPlayer   (SDK 未加载 → 遮罩提示)
       ├─ 读取 HostConfig.Manager || HostConfig.Player 和 Common_config.iid
       ├─ new DigitalTwinPlayer(host, options)
       │     ├─ onReady 回调   → stores/onReady() 场景初始化 + 关闭加载遮罩
       │     ├─ onEvent 回调   → stores/handleEvent(e) 场景事件分发
       │     ├─ onloaded 回调  → player.resize() 自适应
       │     └─ onclose 回调   → handleClose(e) 断线处理(自动重连/提示)
       └─ __g = player.getAPI?.() ?? null   ← 全局 API 接线
```

## 二、VideoStreamPlayer.vue

### 2.1 全局 API 接线(__g)

`__g` 是全项目共用的 AirCity API 对象(声明于 `src/aircity.d.ts`),**在 player 构造完成后立即赋值**(与参考项目一致,不等 onReady):

```ts
player = new window.DigitalTwinPlayer(host, { ... })
__g = player.getAPI?.() ?? null
```

场景代码(`onReady.ts` / `handleEvent.ts` / `view/First`)都直接使用全局 `__g`。

### 2.2 apiOptions(API 初始化选项)

```ts
const apiOptions = {
    onReady: () => { onReady(); loading.value = false }, // 场景初始化 + 关遮罩
    onApiVersion: () => {},      // API 版本回调(暂不处理)
    onEvent: (e) => { handleEvent(e) },  // 场景事件 → stores/handleEvent.ts
    onLog: () => {},             // 屏蔽 SDK 日志
    useColorLog: false           // 仅 SDK 测试页面用,二次开发固定 false
}
```

### 2.3 Player 配置项

| 配置 | 值 | 说明 |
|---|---|---|
| `domId` | `'player'` | 视频流挂载的容器元素 id |
| `iid` | `Common_config.iid` | 云渲染服务 iid,来自宿主页面注入 |
| `pid` | `null` | 工程文件 id;断线 code 4009 时自动补 `?pid=-1` |
| `keyEventReceiver` | `'video'` | 三维键盘交互事件接收者:document / video / none |
| `ui.startupInfo` | `true` | 初始化过程是否显示详细信息 |
| `ui.statusIndicator` | `true` | 左上角闪烁状态指示灯 |
| `ui.statusButton` | `false` | 左下角信息按钮 |
| `ui.fullscreenButton` | `false` | 右下角全屏按钮 |
| `ui.homeButton` | `false` | "回到初始位置"按钮 |
| `ui.taskListBar` | `1` | 任务队列:0 永不显示 / 1 耗时操作时显示 / 2 一直显示 |
| `onloaded` | `handleResize()` | 视频加载完成后自适应一次尺寸 |
| `onclose` | `handleClose()` | 断线处理,见 2.4 |

host 取值:`HostConfig.Manager || HostConfig.Player`(内网/映射地址自适应)。

### 2.4 断线重连机制(handleClose)

| 错误码 | 处理 |
|---|---|
| `4009` | 未指定工程文件 → 当前地址追加 `?pid=-1`(无参数时)或 `&pid=-1` 后整页重载 |
| `1006, 1008, 1013, 4000~4008, 4100~4107`(见 `NEED_RECONNECT_CODES`) | 显示遮罩 → `resetIsOnReady()` → 每 1 秒倒计时 5s → `initPlayer()` 重连 |
| 其他 | 仅遮罩提示 `event.reason` |

### 2.5 加载遮罩

- 初始状态:`loading = true`,文案「系统正在加载......」
- onReady 成功 → `loading = false`,`<transition name="fade">` 淡出
- SDK 未加载 / 配置缺失 / 断线 → 遮罩显示对应原因,不自动消失
- SDK 未加载文案:「AirCity SDK 未加载,请检查 public/aircity 脚本。」
- 配置缺失文案:「视频流配置缺失,请检查 HostConfig 和 Common_config。」

### 2.6 资源销毁(onUnmounted)

```ts
window.removeEventListener('resize', handleResize)
clearInterval(reTimer)        // 清理重连倒计时
player?.destroy?.()           // 销毁播放器
__g?.destroy?.()              // 销毁 API 连接
__g = null
```

## 三、stores/onReady.ts(场景初始化)

`onReady` 在视频流连接成功后被调用,带 `isOnReady` 守卫防止重复执行;断线重连时由组件调用 `resetIsOnReady()` 重置守卫,重连成功后重新初始化。

| 步骤 | 方法 | 内容 |
|---|---|---|
| 1 | `initScene()` | `setCampassVisible(false)` 隐藏指南针;`setMainUIVisibility(false)` 隐藏主 UI;`reset(1)` 重置场景 |
| 2 | `initWeather()` | `disableRainSnow()`;`setDateTime(2026,7,9,10,0)` 白天;`setFogParam(0,0,0,1)`;云 `setCloudDensity(0.4) / setCloudHeight(15) / setCloudThickness(2)`;`setSunIntensity(5)`;`setAmbientLightIntensity(0.6)` |
| 3 | 相机 | `__g.camera.set([612194.809063, 2657027.984844, 413.476406, -18.165979, -24.901295, -0], 0)`(4547 投影坐标 [x, y, z, 俯仰, 偏航, 滚转]) |

## 四、宿主页面依赖

组件依赖宿主页面(index.html 中引入的 AirCity SDK 脚本)注入以下全局对象,缺失时初始化会停在遮罩提示:

| 全局对象 | 用途 | 声明位置 |
|---|---|---|
| `window.DigitalTwinPlayer` | 播放器构造函数 | `aircity.d.ts` |
| `window.HostConfig` | `Manager` / `Player` 服务地址 | `aircity.d.ts` |
| `window.Common_config` | `iid` 等渲染配置 | `aircity.d.ts` |
| `__g`(由组件赋值) | 全项目场景 API 入口 | `aircity.d.ts` |
